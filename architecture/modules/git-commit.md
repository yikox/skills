# git-commit

## 职责

定义并约束 Git 提交信息规范：中文提交、标签化主题行、仓库规则优先级，以及特定远端主机下的动态 AI 共创签名。

## 对外接口

- `$git-commit`：生成、规范化或检查提交信息；用户明确要求时执行提交或推送。
- `git`：读取目标仓库约定、改动范围、当前分支上游和 remote URL。

## 注意点

- 规则优先级为：用户明确要求 > 目标仓库版本化约定 > 远端主机规则 > 通用默认规则。
- 精确匹配目标 remote 主机；当前分支上游优先于 `origin`。
- AI 签名使用实际执行 Agent 的名称，不硬编码身份、邮箱或模型版本。
- 在完整提交信息上判断已有 AI 共创者；人类 `Co-Authored-By` 不阻止追加 AI 共创行。

## 依赖

- 无额外外部依赖；仅使用 Agent 已有上下文和 Git 仓库元数据。
