# Git 提交规范

## 核心规则

### 使用中文提交信息

- 主题行和说明正文使用中文。
- 文件名、函数名、命令、标签和 Git trailer 等技术标识保留必要的英文。
- 主题行描述一个核心行为，包含标签在内不超过 72 个字符。

### 使用主题标签

主题行统一使用 `[tag] 中文摘要` 格式，并按主要改动选择一个标签：

| 标签 | 使用场景 |
| --- | --- |
| `[feature]` | 新增能力或用户可见行为 |
| `[bugfix]` | 修复错误或行为异常 |
| `[refactor]` | 调整实现且不改变预期行为 |
| `[docs]` | 仅修改文档 |
| `[test]` | 仅新增或调整测试 |
| `[chore]` | 构建、配置、依赖或日常维护 |

不要组合多个标签；次要改动放入正文说明。

## 应用仓库差异规则

按以下优先级确定最终规则，低优先级规则不得覆盖高优先级规则：

1. 用户对本次提交的明确要求。
2. 目标仓库中的 `AGENTS.md`、`CLAUDE.md` 或同类版本化约定。
3. 本 Skill 的远端主机规则。
4. 本 Skill 的通用默认规则。

规则不冲突时组合应用；直接冲突时采用优先级更高的规则。

### 识别目标仓库

1. 优先读取当前分支所跟踪 remote 的 URL。
2. 当前分支没有上游时，读取 `origin` 的 URL。
3. 仍无法确定且仓库只有一个 remote 时，使用该 remote。
4. 多个 remote 指向不同主机且无法确定目标时，在生成最终提交信息前让用户确认。
5. 解析 URL 的主机部分并做精确匹配，不使用无边界的字符串包含判断。

### `git.mtlab.meitu.com` 规则

当目标远端主机精确等于 `git.mtlab.meitu.com` 时，在最终提交信息末尾保留一个空行，再追加：

```text
AI-Co-Authored-By: {AGENT_NAME}
```

- 将 `{AGENT_NAME}` 替换为本次实际生成或定稿提交信息的 Agent 名称，例如 `Codex`。
- 从当前运行时身份获取名称；无法可靠确定时先向用户确认，不猜测、不沿用其他 Agent 的名称。
- 除非更高优先级规则明确要求，否则不要擅自添加邮箱或模型版本。
- 非该主机的仓库默认不追加此行，但仍须遵守用户或目标仓库的更高优先级规则。

## 识别已有 AI 共创者

以下任一情况表示提交信息中已存在 AI 共创者，不再追加新的 `AI-Co-Authored-By`：

- 已存在 `AI-Co-Authored-By:` trailer。
- 已存在 `Co-Authored-By:` trailer，且其值明确属于 AI Agent，或目标仓库规则明确将其定义为 AI 签名。

普通人类协作者的 `Co-Authored-By:` 不属于 AI 共创者，不能阻止追加 AI 共创行。检查时忽略 trailer 键的大小写和冒号两侧空白。

## 执行流程

1. 读取目标仓库约定，并检查本次改动范围；不要把无关改动纳入提交。
2. 根据主要改动选择标签，生成中文主题和必要的简短正文。
3. 保留已有正文与 trailer，形成完整的候选提交信息。
4. 识别目标 remote 主机并应用仓库差异规则。
5. 对完整候选消息检查已有 AI 共创者；仅在需要且不存在时追加签名。
6. 去除消息末尾多余空行，确保 AI 共创行位于最末尾并与前文只隔一个空行。
7. 用户仅要求生成、检查或改写时，只返回最终提交信息。
8. 用户明确要求提交或推送时，执行相应 Git 操作；遵守仓库 hook，不使用 `--no-verify` 绕过检查。

最终定稿逻辑：

```text
final_message = 完整的主题 + 正文 + 已有 trailers

if 仓库规则要求 AI 共创行 and final_message 中没有 AI 共创者:
    final_message = 去除末尾空行(final_message)
                    + "\n\nAI-Co-Authored-By: "
                    + 实际 Agent 名称
```

## 示例

普通仓库：

```text
[feature] 新增 Git 提交信息规范
```

`git.mtlab.meitu.com` 仓库，实际 Agent 为 Codex：

```text
[bugfix] 修复重复追加 AI 共创行的问题

AI-Co-Authored-By: Codex
```

## 最终校验

- 主题行是否使用 `[tag] 中文摘要`？
- 标签是否准确反映主要改动且只有一个？
- 是否保留了完整正文和已有 trailers？
- 是否根据正确的目标 remote 应用了仓库规则？
- AI 身份是否来自当前实际 Agent，而不是硬编码值？
- 人类 `Co-Authored-By` 是否未被误判为 AI 共创者？
- 需要的 AI 共创行是否唯一、位于消息最末尾并与前文隔一个空行？
